# Viewpoints Map

| Viewpoint | What to Show | View / Diagram | For Whom |
| :--- | :--- | :--- | :--- |
| **Context** | The system and its external environment (Patient, Doctor, Admin interactions). | C4 System Context | Business Owner, End Users |
| **Container** | Major technical components (Tauri Desktop App, Actix API, PostgreSQL). | C4 Container | Architect, Lead Dev, DevOps |
| **Structural** | Internal backend modules (Auth, Appointments, Repository). | UML Component / Class | Developers |
| **Behavioral** | The sequence of the appointment booking process. | UML Sequence | Backend Developers, QA |
| **Deployment** | Server instances, database hosting, and client distribution. | UML Deployment | DevOps, Security |
