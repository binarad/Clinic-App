# System Description: Clinic-App

## Purpose and Business Goals

Clinic-App is a medical registry and hospital management system designed to automate patient appointment booking and clinical record keeping.
Business Goals:
- Reduce administrative load by enabling self-service online booking for patients.
- Provide doctors with real-time access to their daily schedules.
- Consolidate patient visit histories, diagnoses, and treatments into a single, secure database.

## System Scope

The system includes:
- User registration and role-based authentication ( Patient, Doctor, Admin).
- Browsing available doctors and their schedules.
- Creating, updating, and canceling appointments.
- Recording medical diagnoses and treatments during a visit.
The system **excludes** complex payroll calculations, medical inventory management, and external payment gateway integrations.

## Stakeholders & Concerns Matrix

| Stakeholder | Concern |
| :--- | :--- |
| **Patient** | Fast search for available doctors, data privacy, and a simple booking process. |
| **Doctor** | Stable access to the daily schedule, and a user-friendly interface for entering medical records. |
| **Admin** | Ability to easily manage medical staff profiles and ensure overall system availability. |
| **Developer** | Clear modular structure, testability, and ease of backend maintenance and deployment. |
